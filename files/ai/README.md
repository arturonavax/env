# AI Configuration & Tools

This directory stores transferable configurations and definitions for AI tooling, agents, and workflows.

## Directory Structure

* `mcp/`: Configuration files and server declarations for the Model Context Protocol (MCP).
* `prompts/`: System instructions, prompt templates, rules, and persona specifications.
* `harnesses/`: Configuration and scripts for agent evaluation harnesses and orchestrators.

## Synchronization

* When `./install.sh ai` or `./install.sh all` is executed, these configurations and environments are automatically initialized and synchronized.
