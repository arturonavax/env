## anx completion

Generate or install shell completion script

### Synopsis

Generate or install automatic completion scripts for bash, zsh, fish, or powershell.

Pass --install to write the completion file directly to your shell's user completion path.

```
anx completion <bash|zsh|fish|powershell> [flags]
```

### Examples

```
  # Load zsh completion in current shell
  source <(anx completion zsh)

  # Permanently install zsh completion for current user
  anx completion zsh --install

  # Install bash completion
  anx completion bash --install
```

      --install   Install completion script into user shell completions directory
