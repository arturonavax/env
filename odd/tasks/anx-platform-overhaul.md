- **S2 — Declarative Zero-Go-Edit Configuration for Multi-Distro Packages, Toolchains, From-Source & Curl Recipes**:
  Verbatim: `"maxima versatilidad y flexibilidad, mantenimiento y configuracion sin necesidad directa de tocar el codigo en Go (instalaciones y configuraciones de herramientas/comandos/paquetes declarable en archivos de configuracion en el formato que consideres mas ideal para la ocacion (teniendo en cuenta el sistema multi nombre de paquetes en distintas distribuciones, sistemas de paquetes y sistemas operativos), declaraciones de instalacion con pasos especificos from-sources y curl, etc etc), una muy buena, escalable, mantenible y estable estructura de archivos"`
  Scope & Acceptance:
  - Modular YAML manifests under `manifests/` (`manifests/packages/*.yaml`, `manifests/configs.yaml`, `manifests/profiles.yaml`), embedded via `//go:embed` for standalone binary portability AND dynamically overridable/extensible via `<repo>/manifests/` and `~/.config/anx/manifests.d/*.yaml` without modifying or recompiling Go source.
  - Multi-OS/multi-distro/multi-package-manager translation matrix (`apt`, `dnf`, `pacman`, `zypper`, `apk`, `brew`, `pkg`, `winget`, `scoop`) plus ordered multi-tier fallback strategies: `native`, `github_release` (with SHA-256 verification), `script` (`curl` installers), `source` (`from-source` git clone + declarative build steps like Ghostty Zig `-Doptimize=ReleaseFast`), and `language_pkg` (`go`, `cargo`, `pnpm`, `pipx`).
  - DAG topological dependency resolution and cycle detection.
  - Checks: `go test -race ./internal/manifest/... ./internal/providers/...`.

- **S3 — Native Consolidation of `utils/` into `anx`**:
  Verbatim: `"que muchas de las cosas de @[utils] pasaran a ser parte integral de anx"`
  Scope & Acceptance:
  - Integrate `utils/sync_config.sh` (`anx sync` across `terminal`, `editor`, `plugins`, `plugins-update`, `osconfig`, `vscode`, `cursor`, `devtools`, `ai`, `all` with recursive directory deploy, true 3-way merge backed by `state.json` base hashes, and `SmartAppend` marker blocks), `utils/copy_config.sh` (`anx capture` / `anx sync --push`), `utils/backup_config.sh` + `utils/restore_backup.sh` (`anx backup create|list|restore [--latest|<id>]` with hierarchical file+directory snapshots, SHA-256 manifest, and 50MB quota), `utils/diff_snapshots.sh` (`anx diff` with real unified line & recursive directory diffs), `utils/rebuild_tools.sh` (`anx rebuild [all|go|rust|node|python|nvim]`), `utils/optimize_system.sh` (`anx optimize [--dry-run|--apply|--report]` with hardware/Lynis profiling and 12-rule security guardrail validator), and `utils/create_wizard.sh` / `utils/aitools_wizard.sh` (`anx wizard` & `anx ai setup`).
  - Checks: `go test -race ./internal/configsync/... ./internal/snapshot/... ./internal/ops/...`.

- **S4 — Structured, Declarative Home & Engine for `hacks/`**:
  Verbatim: `"un buen lugar mas concreto para @[hacks] (scripts o configuraciones de sistema especificos para ciertas maquinas personales en las cuales se necesitan operaciones especificas para optimizar)"`
  Scope & Acceptance:
  - Consolidate machine- and hardware-specific hacks under top-level `hacks/<hack-id>/` with declarative `hack.yaml` metadata (hardware/DMI/GPU/DE matchers, modular steps, dry-run checks, backup targets, and documentation), `hacks/embed.go`, and `hacks/README.md`.
  - Migrate `src/hacks/activate_scroll_lock.sh` to `hacks/x11-scroll-lock-led/` (preserving a compatibility shim at `src/hacks/activate_scroll_lock.sh`) and fix hardcoded `/home/arthurnavah` paths in `hacks/dell-precision-m6800/apply_hacks.sh` to use `$HOME` portably.
  - Expose `anx hacks list|detect|info|plan|apply` in CLI and a dedicated `Hacks` view in the TUI.
  - Checks: `go test -race ./internal/hacks/...` && `shellcheck hacks/*/*.sh`.

- **S5 — Complete Go Port of `aitools` Integrated into `anx` & Multicall `aitools` Binary**:
  Verbatim: `"aitools portado a Go bajo los mismos criterios de calidad, TODO para dejar anx en su estado absoluto perfecto como la maxima herramienta de gestion de entorno y scripts y herramientas personales"`
  Scope & Acceptance:
  - Port `files/ai/aitools/aitools` into `internal/ai/` (`config` with pure-Go JSONC parser & deep merge, `harness` adapters for `agy`/`claude`/`codex`/`opencode`/`pi`/`llm`/`ollama`/custom, `contextbuilder` `-f`/`-d` with exclusions & 500KB cap, `gitflow` tracker-agnostic `commit` & template-aware `pr` with multi-platform clipboard, `pipeline` declarative `commands`/`run`, `quota`/`watch`/`wake` with TCP+DNS verification, `daemon` with D-Bus/RTC 04:00 AM alarms, verified wake cycle, cross-platform safe suspend & systemd units, and Bubbletea v2 `setup` wizard).
  - Mount under `anx ai <subcommand>` AND provide standalone/multicall `aitools` binary support (`cmd/aitools/main.go` + `filepath.Base(os.Args[0]) == "aitools"` dispatch in `cmd/anx/main.go`).
  - Checks: `go test -race ./internal/ai/... ./cmd/aitools/...`.

- **S6 — Production Cobra+Viper CLI & Modular Bubble Tea v2 / Lip Gloss v2 TUI**:
  Verbatim: `"sobre todo context7 para las dudas que tengas de bubbletea en Go, lipgloss y Cobra. DEBES GARANTIZAR LA MEJOR IMPLEMENTACION PARA EL PROYECTO, ESCALABLE, MANTENIBLE, CONFIGURABLE, MAXIMO PERFORMANCE Y SEGURIDAD."`
  Scope & Acceptance:
  - CLI (`internal/cli/`): Cobra `RunE`, `SilenceUsage`/`SilenceErrors`, `PersistentPreRunE` with Viper (`ANX_` env prefix + optional `config.yaml`), `AddGroup` command groups, `Args` validators, `ValidArgsFunction` dynamic completions, `OutOrStdout()`/`ErrOrStderr()`, TTY check before TUI launch, `--format text|json|yaml`, and spec exit codes (`0..5`, `130`).
  - TUI (`internal/tui/`): Split into `types.go`, `styles.go`, `model.go`, `update.go`, `update_keyboard.go`, `update_mouse.go`, `view.go`, `wizard.go` adhering strictly to the 4 Bubbletea Golden Rules (border `-2` height subtraction, ANSI-aware truncation via `ansi.Truncate`, layout-matched X/Y `tea.MouseClickMsg`, weight-based 3-breakpoint responsive layouts without `.Height()` on bordered styles, and non-blocking async `tea.Cmd` loading).
  - Checks: `go test -race ./internal/tui/... ./internal/cli/... ./internal/app/...`.

- **S7 — Multi-Platform Pre-Flight Requirement Analyzer & Go Bootstrap (GVM Priority + Personal Fallback)**:
  Verbatim: `"sin olvidarnos de los scripts multiplataforma de install (los cuales deben pasar por algun script multiplataforma de analisis de requisitos para instalar anx (e instalar Golang de necesitarlo, priorizando la instalacion por gvm pero manteniendo el fallback a mi mecanismo de instalacion personal))"`
  Scope & Acceptance:
  - Create `scripts/bootstrap_anx.sh` (Linux/macOS/WSL/Termux) performing pre-flight OS/arch/dependency checks, detecting/provisioning Go >= 1.24 with **GVM priority** (`gvm install go<ver> -B && gvm use go<ver> --default`, fixing the `go1.4 -B`-only bug in `src/lib/toolchain.sh`) -> **fallback to personal mechanism** (`src/remotes/install_golang.sh -i`) -> native package manager fallback, compiling `anx` + `aitools` symlink, and delegating `install.sh` / `uninstall.sh` to `anx`.
  - Create `scripts/bootstrap_anx.ps1` and wire `install.bat` on Windows to perform pre-flight analysis, auto-bootstrap Go via official `go.dev/dl/?mode=json` SHA-256 verified user-space archive (with `winget`/`scoop` fallback), build `anx.exe` & `aitools.exe`, configure user `PATH`, and delegate CLI arguments.
  - Align `specs/anx/*`, `openspec/tasks.md`, and `Makefile` with the final architecture.
  - Checks: `bash -n scripts/bootstrap_anx.sh install.sh uninstall.sh`, `shellcheck scripts/bootstrap_anx.sh install.sh uninstall.sh`, `bash tests/run_tests.sh --lint`, and isolated `HOME` bootstrap dry-run tests.
